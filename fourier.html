Classical synthesis vs the A₀ framework mode
What this implements

Mode A sums the truncated series with no filtering, so the ~9% Gibbs overshoot appears.

Mode B anchors a₀ at 0 (the lim 0/x seed is 0 in ordinary analysis) and caps k at Λ = 1/λ. The literal firewall factor 1−exp(−|Δf|/σ) would zero every amplitude away from jumps, so it is applied as a blend weight g(t) near jumps between plain and σ-smoothed (Lanczos) harmonics. The overshoot reduction is that smoothing, not a physical derivation.

The RN = N(N−1)/2 counter is shown as specified. Actual synthesis cost is k_max terms per sample, which is O(N).
